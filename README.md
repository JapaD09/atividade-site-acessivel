# Jornal Web — Site Acessível

Projeto da atividade “Arrumar o Site Acessível”, de Interação Humano Computador.

## Recursos

- Navegação semântica por economia, tecnologia e esportes.
- Link para pular direto ao conteúdo principal.
- Controles para aumentar e diminuir o tamanho do texto.
- Alternância de alto contraste com indicação do estado do controle.
- Texto alternativo para as imagens, estados de foco visíveis e layout responsivo.

## Como abrir

Abra o arquivo index.html em um navegador. Mantenha os três arquivos do site na mesma pasta.
